# Habit Tracker (Flutter)

A habit tracker for Android, built with Flutter. It keeps the feature set of
the original web reference app, improves the interface, and adds the one thing
the reference was missing: **reminders that actually fire** as real local
notifications, even when the app is closed.

Everything is stored in the phone's own app storage and works fully offline.
Nothing is uploaded anywhere.

## What it does

- **Habits** in three shapes:
  - *Tick* — yes/no once a day, several times a day, or a weekly goal
  - *Measurable* — numbers, distance or time against a daily or weekly target
  - *Weekly goal* — a target for the whole week
- **Build or quit** framing for tick habits
- **Streaks**, a 14-day consistency chart, and per-habit completion rates
- **Plan** tab listing every reminder time for the day, with the next one marked
- **Tasks** — a simple to-do list
- **Focus** tab — a countdown ring, Pomodoro mode with short/long breaks,
  multiple timers, a manual "add session" entry, and a donut chart of where
  your time goes (today / 7 days / 30 days)
- **Dashboard** — progress ring, best streak, time focused today, upcoming
  reminder, streaks, time split and open tasks
- **Reminders** — daily repeating local notifications per habit (the new bit)
- **Backup / restore** — copy your data out as text and paste it back in
- **Settings** — week start day, reminder permission, sample habits, reset

## Getting the APK without Android Studio

The included GitHub Actions workflow builds the APK for you, free.

1. Create a repository on github.com (Public or Private).
2. Upload everything in this folder to the repository root.
3. Open the **Actions** tab, choose **Build Android APK**, and click
   **Run workflow**. (It also runs on its own when you push to `main`.)
4. After a few minutes, open the finished run and download the
   **habit-tracker-apk** artifact. Unzip it to get `app-debug.apk`.
5. Copy the APK to your phone and open it. Allow "Install unknown apps" when
   asked, and choose "Install anyway" if Play Protect warns you.

This is a debug-signed APK, which is fine for your own phone. Publishing to the
Play Store would need a release-signed build.

## Building it yourself

You need Flutter 3.38 or newer (which brings Dart 3.10+) and JDK 17.

```bash
flutter create --platforms=android --org com.habittracker --project-name habit_tracker .
python3 scripts/patch_android.py     # adds notification permissions + desugaring
flutter pub get
flutter build apk --debug
```

The APK lands at `build/app/outputs/flutter-apk/app-debug.apk`.

To run it on a connected device or emulator instead:

```bash
flutter run
```

> The `android/` folder is not committed on purpose. It is generated by
> `flutter create`, which guarantees the Gradle and tool versions match your
> installed Flutter. `scripts/patch_android.py` then layers the app's
> notification settings on top. Run those two commands once after cloning, or
> just open the folder in Android Studio and let it generate the platforms.

## Reminders

Turn them on from **Settings > Reminders** so Android grants notification
permission, then add a time to any habit in the habit editor (step 4). Each
time you change a habit, its reminders are rescheduled automatically. They are
scheduled as inexact daily alarms, which is battery-friendly and does not need
the special exact-alarm permission.

```
    shell.dart           bottom navigation

    habits.dart          habits tab
    plan.dart            reminders tab
    tasks.dart           tasks tab
    focus.dart           focus timer tab
    wizard.dart          4-step habit creator/editor
scripts/patch_android.py prepares the generated Android project
.github/workflows/build-apk.yml builds the APK in the cloud
```

## Data and privacy

Habits, logs, tasks and timers live in the app's private storage as one JSON
blob. Updating by installing a newer APK over the old one keeps your data.
Uninstalling deletes it, so use **Backup** first.
